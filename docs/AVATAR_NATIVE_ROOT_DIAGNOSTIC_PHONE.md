# Native root diagnostic from a phone

Open GitHub Actions → Avatar native root diagnostic. The pull request opening
starts one frozen four-slot capture on hosted Linux x64; no laptop or upload is
required. Open the run summary and artifact avatar-root-retention for results.

This writes a reference graph after the first natural major GC. It does not
request another collection, but it completes some sweeping and changes timing.
Its results cannot qualify the instrument, accept memory, or deploy the app.
Failed and missing captures remain retained. No automatic rerun follows.

Workflow dispatch becomes visible after default-branch registration, subject to
the repository's existing release policy. No merge or release bypass is needed
for the initial pull-request run.
