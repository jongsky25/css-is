# Native handle buffer from a phone

Open GitHub Actions → Avatar native handle buffer. The setup pull request starts
one fixed four-slot cloud capture. No laptop, SSH or upload is needed. Read the
run summary and download avatar-native-handles if desired.

This diagnostic uses native callbacks and records caller addresses for handle
births beyond previously known owners. It adds no Runtime subscription, snapshot,
collection request or wait. It first proves the new buffer's native ABI, clocks,
concurrency and overflow behavior; a failed proof stops before capture.

Unreleased handles are candidates, not proven roots. Every slot/failure is retained.
No automatic rerun, native/application qualification, memory acceptance, product
change, merge or deployment follows. Manual button registration remains subject
to the existing default-branch release policy.
