# Context handle journal from a phone

Open GitHub Actions → Avatar context handle journal. Opening the setup pull
request starts one frozen four-slot capture on hosted Linux x64. No local device,
SSH or upload is required. Read the run summary and avatar-context-journal artifact.

This records context creation/disposal and known owner handle operations without
snapshots, extra waits or GC requests. Both journal-only and journal+membership
slots are instrumented diagnostics; they cannot qualify measurement or accept
product memory. Every slot and failure stays retained. No automatic retry follows.

The workflow's manual button requires default-branch registration under the
existing release policy. No merge or deployment is required for the initial run.
