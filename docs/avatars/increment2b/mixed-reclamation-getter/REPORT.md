## Why this fixture was selected

The preceding path-only getter screen passed cost/integrity checks but observed
no natural collection/page return. Before changing any fixture, retained evidence
from the earlier qualified page-history capability was reviewed. Six runner/hook
hashes verify across three captures. Initial 3f06fd5 recorded 1,023 requests / 652
returns; d732b70's two controlled probes recorded 1,136/551 and 1,254/1,052. Both
observed returns during stage 6 DOM; one also at stage 11 style. This is historical
fixture support, not a replacement for the new instrument's qualification.

The new fixture reproduces the ORIGINAL document bytes: 3,000 div/span/text rows,
3,000 SVG paths, or 3,000 styled divs with fixed CSS rules, repeated DOM/SVG/style
four times. An independent test renders the Handler from frozen d732b70 and requires
byte-for-byte equality for every mode and empty page. No data attributes, extra
allocation pressure, longer dwell or additional documents were added to obtain GC.
The fixed wait remains 220ms. There is no application database or staff data.

Selections are explicit: DOM last 32 divs and last 32 spans; SVG/style preceding
32 and final 32 paths/divs. Each group repeats twice. Labels avatar/other denote
fixture partitions, not actual production avatar ownership. Every probe observes
1,536 declared native getter calls across twelve documents.
