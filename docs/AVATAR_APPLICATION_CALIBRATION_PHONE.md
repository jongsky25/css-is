# Application observer calibration from a phone

The setup PR starts one complete attempt when opened. Open **Checks → Application
observer calibration** for its summary. Download **avatar-application-calibration**
from the run's Artifacts section. You can close your browser while GitHub works.
No local Linux device, terminal, SSH, production account or app secrets are needed.

After default-branch registration, open **Actions → Avatar application observer
calibration → Run workflow**, choose main and confirm. Desktop-site mode in your
phone browser may reveal controls hidden by the mobile layout. Existing main
release/version checks still apply; this PR does not bypass them or deploy.

This verifies the earlier qualified native instrument, proves the real app's
receiver identities, then calibrates four complete synthetic-DB app workloads.
A failed prerequisite stops before those four slots. Every attempted proof/workload
and failure is retained. Do not use Re-run jobs to replace a failed measurement.
A passing observer calibration does not establish memory acceptance or deploy.
Only this workflow and guide are proposed for main; avatar product changes are not
included. The opened-only PR trigger prevents later pushes from repeating runs.
