Reopen an accepted task

Telegram connection and permissions · Review tasks and submissions

Start with /task_reopen in your linked private chat. The concerned case officer or confirmed work lead must have the source reopening authority. Task ownership or Telegram consent alone grants no such authority.

This returns a Done task to In progress for its existing owner. The existing submission, expected output, deadline, history and blockers are preserved. Review the current submission in Office Connect first; stored submission contents stay there. Later submission and acceptance still follow normal rules.

This does not reopen a completed work case or an official document. Reopen completed work through its separate source workflow first. Active formal consolidation review amendments stay in Office Connect so dependent approvals can be reviewed there. The existing owner must still be active and able to read every linked document.
