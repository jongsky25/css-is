# Advisory poster assets

- `Poppins-*.ttf`, `Fraunces.ttf`, `LibreCaslonText.ttf`: SIL Open Font License 1.1 (see the `OFL-*.txt` files). Chosen to approximate the office's Canva design; swap in the exact fonts by replacing these files with the same names.
- `icon_*.png`: Noto Color Emoji glyphs (SIL OFL 1.1) rendered once to PNG so the live server needs no emoji font.
- `bagong_pilipinas.png`: the office-supplied Bagong Pilipinas logo (two-line lockup, transparent background, 545 x 581). The sample poster used the one-line navy wordmark; replace this file to switch.
- The DOH seal is `assets/doh_seal.png`.
